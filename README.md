# Aarav Textiles — B2B Manufacturing Website

A premium frontend website concept for a fictional textile manufacturing company.

The project is designed to demonstrate how a modern B2B textile manufacturer can present its products, manufacturing capabilities, quality standards, and enquiry process to buyers.

> **Demo project:** Aarav Textiles is a fictional company created for portfolio and demonstration purposes. The content, statistics, certifications, testimonials, and contact information are not real.

## Overview

The website focuses on:

* B2B textile manufacturing
* Product presentation
* Manufacturing capabilities
* Quality and inspection processes
* B2B enquiry / quote flow
* Responsive design
* Premium industrial visual design

## Features

* Responsive desktop, tablet and mobile layouts
* Product catalogue
* Product detail pages
* Product filtering and search
* Manufacturing process section
* Factory and infrastructure presentation
* Quality-control section
* Certification showcase
* B2B quote/enquiry form
* Mobile navigation
* Interactive UI states
* Image galleries
* Smooth transitions and micro-interactions

## Tech Stack

* React
* TypeScript
* Tailwind CSS
* Vite

This project was created as a portfolio demonstration for developing professional websites for B2B manufacturing companies.

* Conversion-focused design

## Disclaimer

Aarav Textiles is a fictional company.

All company information, production statistics, certifications, testimonials, market information, and contact details shown on this website are fictional/demo content and should not be interpreted as real business claims.
